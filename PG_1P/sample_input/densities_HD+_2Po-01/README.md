# Description

Sample file `inout.txt` in this directory contains the same basis of 10 ECG functions for the lowest $L = 1$ rovibrational state of the $\mathrm{HD}^+$ ion as `expected_values_HD+_2Po-01` and sets up the calculation of the nucleus-nucleus correlation function $g(x,y)$, the probability density of the internuclear vector $\mathbf{r}_1$ in a plane through the quantization axis ($x$ along the axis, which is the $z$ direction of the $z_i$ prefactor, and $y$ perpendicular to it). For an $L = 1$ state this density is not spherically symmetric, so it is computed on a two-dimensional grid: `cfgrid_x.txt` holds the $x$ values (41 points, 0 to 4 bohr) and `cfgrid_y.txt` the $y$ values (21 points, 0 to 4 bohr), one value per line. The `DENSITIES` line names, in this order, the $x$ grid, the $y$ grid, the output file `corrfunc.txt` (columns $x$, $y$, $g$; $y$ outer, $x$ inner) and the output file `corrfunc_4.txt` with $g$ reflected into all four quadrants, ready for plotting (`none` skips it).
The calculation should take about 1 second on a single CPU core when double precision is used (gfortran compiler / Intel Core i9-7900X class CPU).
The energy should be -0.5955901654; the correlation function peaks on the axis at $x$ = 2.0, $y$ = 0 with $g$ = 0.1312 (a test run gave 0.13121341064926420).
