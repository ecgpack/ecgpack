# Description

Sample file `inout.txt` in this directory contains a basis of 100 ECG functions for the ground state of Li atom (lowest $^2 S^e$ state of Li-7 isotope) and sets up calculations of expectation values for various quantities.
The calculations should take roughly 1-2 seconds on a single CPU core when double precision is used (gfortran compiler / AMD Ryzen 7 7800X3D).
