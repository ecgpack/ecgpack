# Description

Sample file `inout.txt` in this directory contains a basis of 10 ECG functions for the ground state of He atom (lowest $^1 S^e$ state of He-4 isotope) and sets up calculations of expectation values for various quantities.
The calculations should take about 1 second on a single CPU core when double precision is used (gfortran compiler / AMD Ryzen AI 9 HX 370).
