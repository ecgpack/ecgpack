# Description

Sample file `inout.txt` in this directory contains a basis of 10 ECG functions for the ground state of the HD molecule (lowest $^1 S^e$ state; deuteron, proton and two electrons, all treated non-adiabatically) and sets up calculations of expectation values for various quantities.
The calculations should take about 1 second on a single CPU core when double precision is used (gfortran compiler / Intel Core i9-7900X).
The values are printed on the screen and written to `expvals.txt`. The energy should be -1.1508338858.
