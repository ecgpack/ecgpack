# Description

Sample file `inout.txt` in this directory contains a basis of 100 ECG functions for the lowest $^3 P^e$ state of Be atom (Be-9 isotope) and sets up calculations of expectation values for various quantities.
The calculations should take roughly 10-15 seconds on a single CPU core when double precision is used (gfortran compiler / AMD Ryzen 7 7800X3D).
